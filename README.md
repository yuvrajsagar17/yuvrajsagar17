## 👋 Hi there,  

I am a **Deep Learning Engineer** passionate about optimizing **Large Language Models (LLMs)** and **Deep Learning Frameworks** for efficiency and scalability. I specialize in **pretraining, fine-tuning, merging, evaluating, and benchmarking** LLMs as well as leveraging **CUDA C/C++** to accelerate model training and inference. Inspired by [llm.c](https://github.com/karpathy/llm.c) by **Andrej Karpathy**, I have implemented **LLaMA architecture** with custom CUDA optimizations to maximize GPU throughput.  

Along with this, I stay actively engaged with **cutting-edge ML research**, focusing on LLM advancements, AI scalability, and performance optimization.


## 🔬 My Work & Research Focus:  

- **LLM Optimization:** Pretraining, fine-tuning, and benchmarking state-of-the-art architectures on downstream tasks. Merging and quantizing models.
- **CUDA Kernel Development:** Writing high-performance GPU kernels for faster LLM training.  
- **Agentic AI & RAG Pipelines:** Exploring autonomous AI workflows and retrieval-augmented generation.  


## Projects:  

- **[axolotl-finetune](https://github.com/yuvrajsagar17/axolotl-finetune)** – In this project, I've implemented simple and multi-GPU **SFT** for **LLaMA-3.1-8B** model using [Axolotl](https://github.com/axolotl-ai-cloud/axolotl/), conducted Nous evaluation benchmarks. Also quantized model in GGUFs using [llama.cpp](https://github.com/ggerganov/llama.cpp). [Check out Models on HF](https://huggingface.co/yuvraj17)  
- **[llama.c](https://github.com/yuvrajsagar17/llama.c)** – Implementation of **LLaMA3 architecture** using custom CUDA C/C++ kernels for high-performance pretraining on Nvidia GPUs.
